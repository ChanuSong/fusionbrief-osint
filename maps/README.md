# 기본 지도

`countries.geojson`은 Natural Earth 1:110m 국가 윤곽이다. 지리 참고이며 경계에 관한 정치적 판단이나 군사활동 관측 자료가 아니다.

- 원본: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- 이용 조건: https://www.naturalearthdata.com/about/terms-of-use/ (Public Domain)
- 준비: 2026-10-10. geometry를 유지하고 속성을 ADMIN, ISO_A3, NAME_KO, NAME_ZH, LABEL_X, LABEL_Y로 축소했다.
- 외부 타일 서버 대신 이 파일을 앱에서 제공한다. 활동 좌표는 이 지도에서 추출하지 않고 보고서의 검증된 인용에 의존한다.
