## TRACE — 공개 정보에서 검증 가능한 판단으로

TRACE는 자연어 질문을 조사 전략으로 바꾸고, 여러 공개 출처를 수집·교차검증하여 **주장마다 원문 인용과 신뢰도가 연결된 정보분석 보고서와 시각화**를 만드는 Fusion OSINT Copilot입니다.

분석가의 병목은 자료의 부족보다, 흩어진 자료를 어떤 기준으로 대조해 결론을 내릴지에 있습니다. TRACE는 질문에 맞는 판단 기준을 먼저 확인하고 **기준 → 사건 → 주장 → 인용 → 원출처**를 연결합니다. 결론을 읽은 사용자는 클릭으로 근거를 검토하고, 불확실한 부분과 다음 확인 사항까지 추적할 수 있습니다.

## 대표 APAC 시나리오

**“김주애의 북한 후계자 계승 가능성은? 근거와 전망을 분석해줘.”**

통일연구원·38 North의 분석 틀, 국정원 평가를 전달한 보도, KCNA 공개 전달 원문과 북한 배포 사진 등을 대조합니다. 공식 지명·직책, 공개 노출과 호칭, 행사·의전, 실제 권한과 다른 후보·경쟁 설명 등 6개 지표를 통해 후계자 육성 징후와 최종 승계의 불확실성을 구분합니다.

보존한 대표 분석은 **원문 19건 · 유효 사건 인용 15건 · 기준 6개 · 주요 판단 2개 · 조건부 전망 3개 · 검증된 이미지 관측 1개**를 제공합니다. 별도의 최신 실제 실행은 원문 23건·유효 인용 19건을 확보했고 전체 실행은 18분 43초였습니다. 웹 데모와 영상에는 보존 결과 탐색과 실제 수집 화면 기록을 명시합니다.

## 동작 흐름과 핵심 기능

1. **Planner first** — 질의의 명제·범위·모호성을 해석하고 필요한 근거, 우선 출처, 반증, 경쟁 설명, 단계별 완료 조건을 정합니다.
2. **기준 자료 선행 수집** — 공개 연구·교범·법규·공식 정책을 질문에 필요한 경우에만 선택하고, 정확한 조항·판본·적용 범위를 검증합니다. 기준 원문은 SQLite·FTS5에 해시와 판본별로 보존하고 재확인 주기에 따라 재사용합니다.
3. **멀티소스 오케스트레이션** — 정부, 뉴스, 북한 매체, 연구, 공개 논의, SNS, 이미지, 위성, 항공, 해양, 특허의 11개 자료 유형을 사용·조건부·관련 없음으로 계획합니다. 한·중·일·러·영 자료의 원문 수집·번역·내용 대조를 지원합니다. 로동신문·KCNA·KCTV 등 알려진 북한 매체 24종과 보존본 검색도 조사 대상입니다.
4. **인용과 의미를 별도로 검증** — 원문 본문·SHA-256·정확한 인용 위치를 보존합니다. 별도 모델 호출로 주장 적합성, 번역, 사건 시점, 기준·배경·사건의 역할과 기준 적용을 대조합니다. 근거가 부족하거나 검증에 실패한 내용은 제외하거나 판단을 유보합니다.
5. **원출처 독립성에 따른 신뢰도** — 같은 발표의 재인용, 번역본, 동일한 북한 배포 사진을 독립 확인으로 중복 계산하지 않습니다. 기관의 전문성, 주장 적합성, 독립 교차확인, 반증과 정보 공백을 함께 평가하며 가장 약한 핵심 전제가 결론의 신뢰도를 제한합니다. 승계 가능성과 근거 신뢰도는 별개입니다.
6. **읽을 수 있는 인텔 문서** — 핵심 판단 → 기준·사건 대조 → 관측·반대 근거 → 경쟁 설명 → 조건부 전망 → 정보 공백·후속 수집 → 주석·출처 순서입니다. 미 육군 ATP 2-33.4·ODNI ICD 203의 분석 원칙을 참고한 제품 양식이며, 특정 군의 승인된 내부 서식을 주장하지 않습니다.
7. **근거를 탐색하는 시각화** — 기준별 사건 비교, 원출처 묶음, 인물·기관·사건 관계 그래프, 타임라인, 출처가 확인된 좌표 지도, 공개 이미지 대조를 제공합니다. 확인된 결과가 없거나 질문에 의미가 없는 영역은 생략합니다.
8. **분석가 검토·승인** — 출처 병합·분리·독립성 검토, 판단 재검증, 승인·보완 요청과 판본 이력을 기록합니다. 근거 변경 시 승인이 해제됩니다. A4 인쇄/PDF, Markdown, PROV 관계를 포함한 JSON-LD 내보내기를 제공합니다.

## 구현과 검증

React·TypeScript·Vite / Node.js / Cursor CLI의 실제 WebSearch와 구조화 분석 / Zod / SQLite FTS5 / 공개 HTML·PDF·Crossref·EarthSearch STAC / Cytoscape·React Flow·Leaflet.

실제 검색 실행 기록의 URL을 사용하고, 원문을 수집한 뒤 분석 모델에 전달합니다. 공개 사진은 실제 픽셀 읽기 기록과 별도 검증을 통과한 관측만 사용합니다. 온톨로지는 기준·문서 판본·사건·주장·인용·판단·전망을 타입으로 연결하며 관계 무결성을 검사합니다. OWL 추론 엔진이나 통계적으로 보정된 승계 확률을 주장하지 않습니다.

단위·브라우저 검증과 실제 공개자료 수집을 수행했습니다. 저장소에는 실행 방법과 검증 기록을 제공합니다.

## 데모 실행 범위

**DEMO 링크:** 보존한 실제 결과를 로그인 없이 탐색하는 웹 데모입니다. 대표 김주애 분석, 추가 북한 이슈, 다국어·좌표 시각화가 포함된 대만해협 사례, 최신 실제 실행 결과를 볼 수 있습니다.

**새 질문 분석:** 저장소에서 `npm ci`, `agent login`, `npm run dev`로 로컬 앱을 실행합니다. 홈의 분석 실행은 실제 수집 작업을 시작하고, 검색어·접근 URL·확보 원문·실패가 보이는 진행 화면을 거쳐 완료된 보고서로 자동 전환합니다.

공개 자료만 사용합니다. 북한 매체의 직접 접속 실패를 기록하며 전체 매체·발행물을 빠짐없이 수집했다는 뜻은 아닙니다. SNS·항공·해양·특허는 공개 색인 문서·발표 경로이며 전 세계 실시간 AIS/ADS-B 피드는 미연결입니다. Sentinel-2 STAC 메타데이터·미리보기 수집은 검증했고, 질문과 무관하면 보고서에서 생략합니다. 조직 인증·공동 검토 권한은 미구현이며 승인자는 로컬 입력 이름으로 기록합니다.
