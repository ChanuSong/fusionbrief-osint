# 사전 수집 시연 패키지

준비일 2026-10-10. `schema: 1` 패키지의 `run`은 공개 원문 본문·URL·수집 시각·해시, 인용 위치·번역, 주장·관계·검증 상태와 검색 기록을 포함한다.

- `nk-succession.json` (**대표 사례**): 실제 수집 실행 `0fd3a59c-817b-463a-9021-a7416760f6cd`의 공개 원문 19건·유효 인용 15건·지표 6개·주요 판단 2개·조건부 전망 3개. 기반 조사는 약 958초였으며 후속 이미지 보존·픽셀 판독·독립 검증·한국어 번역 대조를 추가했다. 3개 이미지 중 1개의 관측 설명만 통과했다. 텍스트의 해시·인용 위치를 유지하고 승계 분석과 무관한 미사용 교범을 묶음에서 제외했다. 동일 브리핑과 북한 배포 사진이 많아 독립성을 높게 꾸미지 않았다. `durationMs`는 기반 조사와 채택된 후속 검증 소요의 합이다. 검증 탈락 후 폐기한 이전 준비 시도는 포함하지 않는다. 사진 바이트는 `media/{sha256}`에 함께 보존하고 요청마다 해시를 검증한다.
- `taiwan-strait-2026.json` (추가 사례): 공개 문서 10건, 유효 인용 25건, 한국어·중국어·일본어·러시아어·영어. 실제 웹 수집 후, 준비 원문 인덱스로 재분석했다. 최초 초안에서 검증에 실패한 훈련 구역 표기를 제거하고 A구역으로 좁힌 초안을 별도 모델로 재검증했다. 종합 답변도 별도 작성·검증했다. `durationMs`는 기반 웹 수집 실행과 최종 검증·답변 보완 소요의 합으로, 폐기한 준비 시도의 시간은 포함하지 않는다. 저장된 검색 기록에는 실제 웹 검색과 ‘사전 수집 원문 인덱스’가 구분된다. 언어 다양성은 관점의 독립성을 뜻하지 않는다.
- `nk-pow-disclosure.json`: 공개 문서 10건, 유효 인용 18건. 기존 실제 수집 보고서의 통합 답변을 보완·검증한 결과. 양국의 주장과 정보당국의 동기 해석을 구분한다.

세 원본은 분석가 검토·승인 전 상태다. `POST /api/demo/start`는 새 ID의 복사본을 만들어 원본을 보존한다. 클라이언트가 임의 보고서 내용을 이 API로 주입할 수 없고 등록된 시연 ID만 받는다. 인용·해시·참조를 시작할 때 다시 확인한다.

`npm run demo:verify`로 패키지 무결성과 시연 자료 범위를 검사한다. 새 시연을 준비할 때는 새 웹 조사 결과의 원문과 인용을 검토한 후 `npm run demo:package -- run.json id title subtitle [--main]`를 실행한다. 검토·승인 이력이 있는 결과는 검토 전 원본으로 변환할 수 없다.
